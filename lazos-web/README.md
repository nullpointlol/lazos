# LAZOS Web - Frontend

Este directorio contiene el frontend de LAZOS, desarrollado con **React 18.2, Vite 5, Tailwind CSS y React Leaflet**.

## 📚 Documentación y Flujo de Desarrollo

Todo el desarrollo técnico, guías de estilo del frontend, configuración PWA y planes de remedición están centralizados para mantener una única fuente de verdad (SSoT) y evitar inconsistencias:

*   📖 **[Guía Principal de Agentes IA](../docs/ai/README.md)**: El punto de partida de toda la documentación.
*   🧭 **[Guía de Arquitectura del Proyecto](../docs/ai/02-ARCHITECTURE.md)**: Información detallada sobre el stack y directorios.
*   🎨 **[Guía detallada del Frontend](../docs/ai/06-FRONTEND-GUIDE.md)**: Descripción de componentes, hooks personalizados y páginas.
*   ⚙️ **[Guía de Configuración e Instalación](../docs/ai/08-DEPLOYMENT.md)**: Variables de entorno locales y producción.
*   🛠️ **[AGENTS.md](../AGENTS.md)**: reglas de código y commits.

Para instrucciones de ejecución local rápidas, consulta la sección **Instalación** del [README principal](../README.md).
