# LAZOS API - Backend

Este directorio contiene el backend de LAZOS, desarrollado con **Python 3.11, FastAPI, SQLAlchemy 2.0 y PostgreSQL (PostGIS + pgvector)**.

## 📚 Documentación y Flujo de Desarrollo

Todo el desarrollo técnico, esquemas de base de datos, APIs de referencia y planes de remedición están centralizados para mantener una única fuente de verdad (SSoT) y evitar inconsistencias:

*   📖 **[Guía Principal de Agentes IA](../docs/ai/README.md)**: El punto de partida de toda la documentación.
*   🧭 **[Guía de Arquitectura del Proyecto](../docs/ai/02-ARCHITECTURE.md)**: Información detallada sobre el stack y directorios.
*   📐 **[Esquemas y Modelos de Base de Datos](../docs/ai/04-DATABASE-MODELS.md)**: Estructura de tablas y tipos geoespaciales.
*   📡 **[Referencia de API](../docs/ai/05-API-REFERENCE.md)**: Endpoints REST, esquemas de entrada y de salida.
*   ⚙️ **[Guía de Configuración e Instalación](../docs/ai/08-DEPLOYMENT.md)**: Variables de entorno, R2 Storage y Cloudflare AI.
*   🛠️ **[AGENTS.md](../AGENTS.md)**: reglas de código y commits.

Para instrucciones de ejecución local rápidas, consulta la sección **Instalación** del [README principal](../README.md).
